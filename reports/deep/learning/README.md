# Persistence and adaptation: one action-level case

Start with [the report](math-definition-report.md): an earlier executable definition correction returned as a new, passing-but-misspecified verifier; the agent then retracted the published result and changed subsequent computation.

- [Evidence packet](math-definition-evidence.json): 15 chronological anchors, complete export provenance, field-specific exact quotes, server and independently recomputed raw-row SHA-256 checks. Only reviewed excerpts are retained; all raw rows were complete. Total raw bytes inspected for these anchors: 59,565.
- [Investigation recipe](investigation-recipe.json): tested requests, branch reasons, expected anchors, failure cases, and acceptance criteria. Seed prompt: **“Did an agent repeat a mistake it had already corrected? Show the actions, consequences, and recovery.”**
- [Scope and query log](scope-query-log.json): metadata for 22 exploratory/replay response pages, including truncation and source coverage. This is not a complete timestamped network trace; entries with unrecoverable exact request parameters are marked and excluded from the replay.
- [Verification script](verify_packet.py): re-fetches the fixed 15 selected records and corresponding raw rows, checks hashes and exact named-field substrings, and rewrites the evidence packet. Run from repository root with `PYTHONDONTWRITEBYTECODE=1 python3 reports/deep/learning/verify_packet.py`. It uses the existing local token file through `query.py`; it never runs trace commands.

The seed replay is retrospective. The original investigation began with a supplied secondary-news clue; it did not autonomously discover this case from the minimal prompt. All 15 anchors are found in the listed replay pages, but choosing the queries/windows and evaluating their meaning still required an analyst. The reconstruction lists 11 search/context calls and 30 record/raw validation calls. Additional exploratory attempts are not hidden inside that 41-call count.

A reviewer should challenge the semantic link between the earlier corrected code and later conjecture 302, the separation between code written and code executed, and the strength of the publication/retraction artifact chain. Hashes verify exported bytes, not mathematical validity. The report does not establish deliberate deception, permanent forgetting, a learning rate, general model behavior, or correction durability beyond the observed follow-on scanner. Proposed platform improvements are untested.
